## Run it

```sh

```

The runner writes `entry.png` to `${MAKEFUN_OUTPUT_DIR:-/output}`. To redraw the original artwork, run `python3 draw_news.py` with Pillow 10.2.0 and the Noto Sans TrueType fonts installed. Set `NOTO_SANS_DIR` if the fonts are outside `/usr/share/fonts/truetype/noto`.
